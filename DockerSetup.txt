❌ 10. Found the MiniLM container issue

Backend reached Spring Boot startup but failed at:

HybridEmbeddingService

The exact reason:

model.onnx ... does not reside in the file system

Because your code used:

modelResource.getFile()

That works when running from the filesystem but not when the resource is inside a Spring Boot JAR.

🔧 11. We're fixing that now

We're changing the MiniLM loading process to:

JAR resource
    ↓
InputStream
    ↓
temporary file inside container
    ↓
ONNX Runtime

So the model remains local and bundled; we're just making its loading Docker-compatible.
